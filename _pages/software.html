R packages and software developed or co-developed as part of my research.
alphahull
Beatriz Pateiro-López and Alberto Rodríguez-Casal
Generalization of the convex hull of a sample of points in the plane. The package computes alpha-shapes and alpha-convex hulls and includes tools for Delaunay triangulations and Voronoi diagrams.
CRAN
alphashape3d
Thomas Lafarge and Beatriz Pateiro-López
Implementation of the alpha-shape of a finite set of points in three-dimensional space. The package provides tools for reconstructing non-convex and disconnected 3D sets, computing volumes, identifying connected components, and visualizing alpha-shapes.
CRAN
ASML
Brais González-Rodríguez, Ignacio Gómez-Casares, Beatriz Pateiro-López and Julio González-Díaz
Algorithm Portfolio Selection with Machine Learning. The package provides methods for selecting among a portfolio of algorithms using machine-learning models trained to predict a key performance indicator for each candidate algorithm.
CRAN
