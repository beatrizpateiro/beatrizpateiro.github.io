Introdución á regresión lineal

En moitas situacións prácticas non só interesa describir unha variable, senón comprender como cambia en función doutras.

  • Analizar como se comporta o peso en función da estatura

  • Analizar como inflúe o tamaño dun conxunto de datos de adestramento na precisión dun modelo de aprendizaxe automática

  • Estudar como cambia o tempo de adestramento dun modelo en función do número de parámetros ou das características empregadas

Modelos de regresión

Teñen como obxectivo describir e predicir o valor dunha variable numérica chamada variable resposta (\(Y\)) a partir dunha ou máis variables explicativas (\(X_1, X_2,\ldots, X_p\)). Estes modelos permiten non só analizar relacións, senón tamén realizar predicións para novos datos.

\[Y=f(X_1,\ldots,X_p)+\epsilon\]

Introdución á regresión lineal

Considérase que a variable resposta \(Y\), que asumimos depende dunha única variable explicativa \(X\). Na práctica, non observamos toda a poboación, senón unha mostra de tamaño \(n\), formada por pares de observacións da forma \((x_1,y_1),\ldots,(x_n,y_n).\)

Introdución á regresión lineal

O diagrama de dispersión. Consiste en representar nunha cuadrícula os pares de observacións \((x_i, y_i)\) de cada individuo da mostra. A nube de puntos que se forma tamén se chama nube de puntos ou scatter plot

  • Amosa a posible relación entre as dúas variables e detectar patróns lineais ou non lineais.
    • Se non hai relación, a nube aparecerá dispersa sen patrón definido.
    • Se hai relación lineal os puntos tenden a agruparse arredor dunha liña ascendente pou descendente.
    • Se hai relación non lineal a tendencia dos puntos segue unha curva, por exemplo, unha parábola ou un patrón sen liña recta clara.
  • Permite identificar posibles valores atípicos.

Introdución á regresión lineal

Covarianza

Sexan \((x_1, y_1), (x_2, y_2), \ldots, (x_n, y_n)\) un conxunto de \(n\) observacións das variables \(X\) e \(Y\). Defínese a covarianza como:

\[ s_{xy} = \frac{(x_1-\bar{x})(y_1-\bar{y}) + \ldots + (x_n-\bar{x})(y_n-\bar{y})}{n} = \frac{1}{n}\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y}) \]

A covarianza pódese interpretar como unha medida de relación lineal entre as variables \(X\) e \(Y\):

  • Valores positivos indican que cando \(X\) aumenta, \(Y\) tende a aumentar.
  • Valores negativos indican que cando \(X\) aumenta, \(Y\) tende a diminuír.
  • Valores próximos a cero indican que non hai unha relación lineal clara.

Propiedades:

  • A covarianza de \((X, Y)\) é igual á de \((Y, X)\), é dicir, \(s_{xy} = s_{yx}\)
  • A covarianza de \((X, Y)\) é igual á varianza de \(X\), é dicir, \(s_{xx} = s_x^2\)

En R, a función cov() calcula por defecto a covarianza con denominador \(n-1\). Para obter a covarianza definida teoricamente neste tema (dividindo entre \(n\)), é preciso facer a corrección que se amosa.

datos <- read.csv2("enquisa.csv")
n <- nrow(datos)
cov(datos$Altura, datos$Peso) * (n - 1)/n
## [1] 60.41736

Introdución á regresión lineal

Coeficiente de correlación lineal

Sexan \((x_1, y_1), (x_2, y_2), \ldots, (x_n, y_n)\) un conxunto de \(n\) observacións das variables \(X\) e \(Y\). Defínese o coeficiente de correlación lineal como:

\[ r_{xy} = \frac{s_{xy}}{s_x s_y} \]

  • O coeficiente de correlación lineal toma valores en [-1,1] e serve para investigar a relación lineal entre as variables.
    • Se \(r_{xy}\) é próximo a \(-1\), temos unha relación inversa entre \(X\) e \(Y\), é dicir, cando unha variable toma valores altos, a outra tende a ser baixa.
    • Se \(r_{xy}\) é próximo a \(+1\), temos unha relación directa, de modo que valores altos dunha variable están asociados con valores altos da outra.
    • Se \(r_{xy}\) é próximo a cero, non existe relación lineal significativa entre as variables.

\[ r_{xy} = \frac{s_{xy}}{s_x s_y} \]

O modelo de regresión lineal simple

Un dos modelos de regresión máis sinxelos é a regresión lineal simple, na que se supón que a variable resposta \(Y\) depende dunha única variable explicativa \(X\) e que a relación entre ambas pode aproximarse mediante unha recta.

Modelo de regresión lineal simple

\[ Y = \beta_0 + \beta_1 X + \varepsilon \]

  • \(\beta_0\) é o intercepto,
  • \(\beta_1\) é a pendente,
  • \(\varepsilon\) é o termo de erro.

Estimación do modelo

Modelo de regresión lineal simple

\[ Y = \beta_0 + \beta_1 X + \varepsilon \]

  • \(\beta_0\) é o intercepto,
  • \(\beta_1\) é a pendente,
  • \(\varepsilon\) é o termo de erro.

Na práctica, os parámetros \(\beta_0\) e \(\beta_1\) son descoñecidos e deben estimarse a partir dunha mostra:

\[ (x_1,y_1), \ldots, (x_n,y_n). \] A recta estimada obtense mediante o método dos mínimos cadrados, e escríbese como:

\[ \hat{Y} = \hat{\beta}_0 + \hat{\beta}_1 X. \]

Estimación do modelo. Método dos mínimos cadrados

Os erros de predición defínense como:

\[ e_i = y_i - \hat{y}_i = y_i - (\hat{\beta}_0 + \hat{\beta}_1 x_i). \]

O obxectivo é minimizar a suma dos erros ao cadrado:

\[ ECM(\beta_0,\beta_1)=\frac{1}{n}\sum_{i=1}^n (y_i-(\beta_0+\beta_1 x_i))^2. \]

Estimadores resultantes de minimizar \(ECM(\beta_0,\beta_1)\)

\[ \hat{\beta}_1 = \frac{s_{xy}}{s_x^2}, \quad \hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}. \]

Recta de regresión de \(Y\) sobre \(X\)

\[ \hat{y} = \hat{\beta}_0+\hat{\beta}_1 x = \bar{y} + \frac{s_{xy}}{s_x^2} (x - \bar{x}). \]

Recta de regresión de \(Y\) sobre \(X\)

Recta de regresión de \(Y\) sobre \(X\)

\[ \hat{y} = \hat{\beta}_0+\hat{\beta}_1 x = \bar{y} + \frac{s_{xy}}{s_x^2} (x - \bar{x}). \]

Coeficientes da recta de regresión

\[ \hat{\beta}_1 = \frac{s_{xy}}{s_x^2}= 0.730208\]

\[ \hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x} =-61.2789 \]

datos <- read.csv2("enquisa.csv")
y <- datos$Peso
x <- datos$Altura
b1 <- cov(x, y)/var(x)
b1
## [1] 0.730208
b0 <- mean(y) - b1 * mean(x)

# La recta de regresión es Y=b0+b1*X

Descomposición da variabilidade

\(\text{Variabilidade Total} = \text{Variabilidade Explicada} + \text{Variabilidade Non Explicada}\)

\[ VT = VE + VNE. \]

\[\sum_{i=1}^n (y_i - \bar{y})^2=\sum_{i=1}^n (\hat{y}_i - \bar{y})^2+\sum_{i=1}^n (y_i - \hat{y}_i)^2\]

  • Variabilidade total: \(VT = \sum_{i=1}^n (y_i - \bar{y})^2.\)

  • Variabilidade explicada: \(VE = \sum_{i=1}^n (\hat{y}_i - \bar{y})^2\)

  • Variabilidade non explicada: \(VNE = \sum_{i=1}^n (y_i - \hat{y}_i)^2\)

Coeficiente de determinación

Coeficiente de determinación

\[ R^2 = \frac{VE}{VT} = 1 - \frac{VNE}{VT}. \]

Ademáis, no caso da regresión lineal simple:

\[ R^2 = r_{xy}^2. \]

  • O coeficiente \(R^2\) mide a proporción da variabilidade explicada polo modelo.
  • Toma valores entre 0 e 1.
  • Canto máis próximo a 1 sexa o seu valor, maior será a capacidade do modelo para explicar a variabilidade dos datos.
  • Pola contra, valores próximos a 0 indican que o modelo explica pouca variabilidade.
