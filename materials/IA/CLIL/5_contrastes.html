5  Contrastes de hipóteses

Nesta práctica aplicaremos os conceptos de contrastes de hipóteses estudados na teoría utilizando o entorno de programación R. O obxectivo é que aprendamos a formular hipóteses estatísticas, calcular estatísticos de contraste e interpretar os p-valores para tomar decisións sobre parámetros dunha poboación a partir de mostras.

5.1 Conceptos básicos

Un contraste de hipóteses é un procedemento estatístico que permite tomar unha decisión sobre un parámetro descoñecido dunha poboación a partir dunha mostra. Para iso formúlanse dúas hipóteses:

  • Hipótese nula \(H_0\): representa a afirmación inicial sobre o parámetro. É a hipótese que asumimos certa antes de observar os datos. Goza de presunción de inocencia, de modo que só se rexeitará se hai evidencia suficiente en contra dela.
  • Hipótese alternativa \(H_1\): representa a afirmación que se acepta se a evidencia da mostra é suficientemente forte contra \(H_0\).

A decisión baséase nun estatístico de contraste, cuxa distribución baixo \(H_0\) é coñecida. Ao fixar un nivel de significación \(\alpha\), obtense implícitamente unha división en dúas rexións do conxunto de posibles valores do estatístico de contraste:

  • A rexión de rexeitamento ou rexión crítica, que ten probabilidade \(\alpha\) (baixo \(H_0\)).
  • A rexión de aceptación, que ten probabilidade \(1-\alpha\) (baixo \(H_0\)).

Se o valor do estatístico cae na rexión de aceptación, non existen razóns suficientes para rexeitar a hipótese nula cun nivel de significación \(\alpha\), e o contraste considérase estatísticamente non significativo, é dicir, non existe evidencia a favor de \(H_1\). Se o valor do estatístico cae na rexión de rexeitamento, os datos non son compatibles con \(H_0\) e rexeitamos a hipótese. Entón dicimos que o contraste é estatísticamente significativo, é dicir, existe evidencia estatisticamente significativa a favor de \(H_1\).

Tamén podemos tomar a decisión a partir do denominado p-valor do estatístico, que mide a evidencia da mostra contra a hipótese nula. Dado un nivel de significación \(\alpha \in [0,1]\), a regra de decisión é:

  • Se \(\textnormal{p-valor} < \alpha\) rexeitamos \(H_0\) a nivel \(\alpha\).
  • Se \(\textnormal{p-valor} > \alpha\) non rexeitamos \(H_0\) a nivel \(\alpha\).

5.2 Contrastes para a media dunha poboación normal

Consideremos unha mostra aleatoria simple \(X_1,\dots,X_n\) de tamaño \(n\) procedente dunha poboación normal \(N(\mu,\sigma)\). O obxectivo é formualr contrastes relativos á media poboacional \(\mu\).

5.2.1 Contrastes para a media con varianza coñecida

Supoñamos que a varianza da poboación \(\sigma^2\) é coñecida. Queremos en primeiro lugar contrastar se a media da poboación é igual a un determinado valor \(\mu_0\). Formulamos o contraste

\[ H_0:\mu=\mu_0 \qquad \text{fronte a} \qquad H_1:\mu\neq\mu_0. \]

Se a varianza da poboación é coñecida, o estatístico de contraste é

\[ Z=\frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}, \]

que segue unha distribución normal estándar \(N(0,1)\) cando \(H_0\) é certa.

TipContraste bilateral \(H_0:\mu=\mu_0\) fronte a \(H_1:\mu\neq\mu_0\) (\(\sigma^2\) coñecida)

Rexeitamos \(H_0:\mu=\mu_0\) fronte a \(H_1:\mu\neq \mu_0\) para un nivel \(\alpha\) se

\[ \frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}\leq -z_{\alpha/2} \quad \text{ou} \quad \frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}\geq z_{\alpha/2} \]

Isto é equivalente a comprobar se o p-valor é menor que \(\alpha\).

Como exemplo, supoñamos unha plataforma de comercio electrónico que quere comprobar se o tempo medio de resposta do seu sistema é distinto de 5 ms. Para iso mídese o tempo de resposta en 10 usuarios:

\[ 5.31,\ 5.36,\ 4.96,\ 5.17,\ 5.29,\ 5.12,\ 5.12,\ 5.30,\ 5.31,\ 5.46 \]

Suponse que a variable é normal con desviación típica \(\sigma=0.3\). Para un nivel de significación \(\alpha=0.05\), ¿podemos asumir que o tempo medio de resposta é distinto de 5 ms?

x <- c(5.31, 5.36, 4.96, 5.17, 5.29, 5.12, 5.12, 5.3, 5.31, 5.46)
sigma <- 0.3
mu0 <- 5
alpha <- 0.05

n <- length(x)
xbar <- mean(x)
xbar
## [1] 5.24

# Estatístico de contraste
z <- (xbar - mu0)/(sigma/sqrt(n))
z
## [1] 2.529822

# Valor crítico
z_alpha2 <- qnorm(1 - alpha/2)
z_alpha2
## [1] 1.959964

# Decisión a partir da rexión crítica
if (z > z_alpha2 | z < (-z_alpha2)) {
    decision <- "Para un nivel alpha=0.05, rexeitamos H0: hai evidencia de que o tempo medio non é 5 ms."
} else {
    decision <- "Para un nivel alpha=0.05, non rexeitamos H0: os datos son compatibles cun tempo medio de 5 ms."
}
decision
## [1] "Para un nivel alpha=0.05, rexeitamos H0: hai evidencia de que o tempo medio non é 5 ms."

# Decisión a partir do p-valor
p_valor <- 2 * (1 - pnorm(abs(z)))

cat("Estatístico de contraste Z =", z, "\n")
## Estatístico de contraste Z = 2.529822
cat("p-valor =", p_valor, "\n")
## p-valor = 0.01141204
cat("Rexeitamos H0 para valores alpha maiores que", p_valor, "\n")
## Rexeitamos H0 para valores alpha maiores que 0.01141204

5.2.2 Contrastes para a media con varianza descoñecida

Supoñamos agora que a varianza da poboación \(\sigma^2\) é coñecida. Queremos formular o contraste

\[ H_0:\mu=\mu_0 \qquad \text{fronte a} \qquad H_1:\mu\neq\mu_0. \] Neste caso, o estatístico de contraste é

\[ \frac{\bar{X}-\mu_0}{S/\sqrt{n}}, \]

que segue unha distribución \(t\) de Student con \(n-1\) grados de liberdade cando \(H_0\) é certa.

TipContraste bilateral \(H_0:\mu=\mu_0\) fronte a \(H_1:\mu\neq\mu_0\) (\(\sigma^2\) descoñecida)

Rexeitamos \(H_0:\mu=\mu_0\) fronte a \(H_1:\mu\neq \mu_0\) para un nivel \(\alpha\) se

\[ \frac{\bar{X}-\mu_0}{S/\sqrt{n}}\leq -t_{n-1,\alpha/2} \quad \text{ou} \quad \frac{\bar{X}-\mu_0}{S/\sqrt{n}}\geq t_{n-1,\alpha/2} \]

Isto é equivalente a comprobar se o p-valor é menor que \(\alpha\).

Como exemplo, supoñamos unha plataforma de comercio electrónico que quere comprobar se o tempo medio de resposta do seu sistema é distinto de 5 ms. Para iso mídese o tempo de resposta en 10 usuarios:

\[ 5.31,\ 5.36,\ 4.96,\ 5.17,\ 5.29,\ 5.12,\ 5.12,\ 5.30,\ 5.31,\ 5.46 \]

Suponse que a variable é normal con desviación típica descoñecida. Para un nivel de significación \(\alpha=0.05\), ¿podemos asumir que o tempo medio de resposta é distinto de 5 ms?

x <- c(5.31, 5.36, 4.96, 5.17, 5.29, 5.12, 5.12, 5.3, 5.31, 5.46)
mu0 <- 5
alpha <- 0.05

n <- length(x)
xbar <- mean(x)
S <- sd(x)

# Estatístico de contraste
T <- (xbar - mu0)/(S/sqrt(n))
T
## [1] 5.212467

# Valor crítico
t_alpha2 <- qt(1 - alpha/2, n - 1)
t_alpha2
## [1] 2.262157

# Decisión a partir da rexión crítica
if (T > t_alpha2 | T < (-t_alpha2)) {
    decision <- "Para un nivel alpha=0.05, rexeitamos H0: hai evidencia de que o tempo medio non é 5 ms."
} else {
    decision <- "Para un nivel alpha=0.05, non rexeitamos H0: os datos son compatibles cun tempo medio de 5 ms."
}
decision
## [1] "Para un nivel alpha=0.05, rexeitamos H0: hai evidencia de que o tempo medio non é 5 ms."

# Decisión a partir do p-valor
p_valor <- 2 * (1 - pt(abs(T), n - 1))

cat("Estatístico de contraste T =", T, "\n")
## Estatístico de contraste T = 5.212467
cat("p-valor =", p_valor, "\n")
## p-valor = 0.0005547442
cat("Rexeitamos H0 para valores alpha maiores que", p_valor, "\n")
## Rexeitamos H0 para valores alpha maiores que 0.0005547442

Rexeitamos a hipótese nula \(H_0:\mu\leq\mu_0\) fronte a \(H_1:\mu>\mu_0\) se

\[ \frac{\bar{X}-\mu_0}{S/\sqrt{n}}\geq t_{\alpha} \]

Isto é equivalente a comprobar se o p-valor é menor que \(\alpha\).

En R, os contrastes para a media cunha varianza descoñecida pódense realizar directamente coa función t.test(). Esta función calcula automaticamente o estatístico de contraste e o p-valor. O argumento alternative indica o tipo de contraste que queremos realizar.

  • alternative = "two.sided" realiza un contraste bilateral (\(H_1:\mu\neq \mu_0\) )

  • alternative = "greater" realiza un contraste unilateral á dereita (\(H_1:\mu>\mu_0\)).

  • alternative = "less" realiza un contraste unilateral á esquerda (\(H_1:\mu<\mu_0\)).

Empregando os mesmos datos do exemplo anterior:

x <- c(5.31, 5.36, 4.96, 5.17, 5.29, 5.12, 5.12, 5.3, 5.31, 5.46)
mu0 <- 5

# Cotraste bilateral
t.test(x, mu = mu0, alternative = "two.sided")

5.3 Contrastes para a diferenza de medias

Moitas veces queremos comparar as medias de dúas poboacións, xa sexa de dúas poboacións diferentes ou de dúas medicións sobre os mesmos individuos dunha poboación. Segundo o tipo de datos dispoñibles, a comparación realízase con mostras independentes ou mostras emparelladas, nas que se obteñen dúas observacións relacionadas para cada individuo. Neste caso, traballaremos unicamente co caso de varianzas descoñecidas, que é o máis habitual en aplicacións reais. Todos os contrastes realizaranse de forma directa mediante a función t.test() de R, que implementa automaticamente os procedementos baseados na distribución \(t\) de Student para mostras independentes e emparelladas. Ademais, neste punto deixaremos de calcular explicitamente os estatísticos de contraste e as rexións críticas en cada caso, xa que estes detalles poden consultarse no material teórico. Na práctica centrámonos na interpretación do p-valor e na decisión estatística final.

5.3.1 Mostras independentes, varianzas descoñecidas e iguais

Supoñamos dúas poboacións nas que se estudan dúas características distribuídas normalmente con medias descoñecidas \(\mu_1\) e \(\mu_2\), respectivamente. Estamos interesados en realizar contrates sobre a diferencia de medias \(\mu_1-\mu_2\) a partir de dúas mostras:

  • Unha mostra formada por \(n_1\) variables independentes e coa mesma distribución \(N(\mu_1, \sigma_1)\).
  • Unha mostra formada por \(n_2\) variables independentes e coa mesma distribución \(N(\mu_2, \sigma_2)\).

As mostras considéranse independentes e supoñemos que as varianzas son descoñecidas pero iguais.

Como exemplo, supoñamos de novo unha plataforma de comercio electrónico que compara o tempo medio de resposta do seu sistema en dous servidores distintos. Supoñemos que as varianzas dos tempos de resposta en cada servidor son descoñecidas pero iguais. Obsérvanse os tempos de 10 usuarios distintos en cada servidor:

  • Servidor 1: \(5.60, 5.10, 5.35, 5.75, 5.20, 5.70, 5.45, 5.30, 5.65, 5.25\)
  • Servidor 2: \(5.10, 4.80, 4.85, 5.20, 4.90, 5.00, 4.95, 4.88, 5.05, 4.92\)

Queremos contrastar se existen diferenzas entre os tempos medios dos dous servidores.

\[ H_0:\mu_1=\mu_2 \qquad \text{fronte a} \qquad H_1:\mu_1\neq\mu_2 \] En R, podemos realizar directamente este contraste coa función t.test() indicando as dúas mostras e o argumento var.equal = TRUE.

x1 <- c(5.6, 5.1, 5.35, 5.75, 5.2, 5.7, 5.45, 5.3, 5.65, 5.25)
x2 <- c(5.1, 4.8, 4.85, 5.2, 4.9, 5, 4.95, 4.88, 5.05, 4.92)

t.test(x1, x2, var.equal = TRUE, alternative = "two.sided")
## 
##  Two Sample t-test
## 
## data:  x1 and x2
## t = 5.7263, df = 18, p-value = 1.983e-05
## alternative hypothesis: true difference in means is not equal to 0
## 95 percent confidence interval:
##  0.2975622 0.6424378
## sample estimates:
## mean of x mean of y 
##     5.435     4.965

Observamos que o p-valor é moi pequeno (inferior a 0.05), polo que rexeitamos a hipótese nula. Polo tanto, existe evidencia estatística suficiente para concluír que os tempos medios de resposta dos dous servidores son diferentes. Agora, se o que nos interesa é determinar se o tempo medio no servidor 1 é maior que no servidor 2, formulamos un contraste unilateral:

\[ H_0:\mu_1\leq\mu_2 \qquad \text{fronte a} \qquad H_1:\mu_1>\mu_2 \]

x1 <- c(5.6, 5.1, 5.35, 5.75, 5.2, 5.7, 5.45, 5.3, 5.65, 5.25)
x2 <- c(5.1, 4.8, 4.85, 5.2, 4.9, 5, 4.95, 4.88, 5.05, 4.92)

t.test(x1, x2, var.equal = TRUE, alternative = "greater")
## 
##  Two Sample t-test
## 
## data:  x1 and x2
## t = 5.7263, df = 18, p-value = 9.917e-06
## alternative hypothesis: true difference in means is greater than 0
## 95 percent confidence interval:
##  0.3276729       Inf
## sample estimates:
## mean of x mean of y 
##     5.435     4.965

De novo, o p-valor é moi pequeno, polo que, para calquera nivel de significación razoable, rexeitamos a hipótese nula. Existe evidencia estatística suficiente para concluír que o servidor 1 presenta un tempo medio de resposta maior que o servidor 2.

Nota

É importante ter en conta que en t.test() a orde na que se introducen as mostras é relevante, xa que determina a interpretación das hipóteses. En particular, a primeira mostra introducida considérase como referencia para o cálculo da diferenza de medias. Isto é especialmente importante nos contrastes unilaterais, xa que o sentido da hipótese alternativa depende directamente da orde na que se introducen os datos.

5.3.2 Mostras independentes, varianzas descoñecidas e distintas

Supoñamos dúas poboacións nas que se estudan dúas características distribuídas normalmente con medias descoñecidas \(\mu_1\) e \(\mu_2\), respectivamente. Estamos interesados en realizar contrates sobre a diferencia de medias \(\mu_1-\mu_2\) a partir de dúas mostras:

  • Unha mostra formada por \(n_1\) variables independentes e coa mesma distribución \(N(\mu_1, \sigma_1)\).
  • Unha mostra formada por \(n_2\) variables independentes e coa mesma distribución \(N(\mu_2, \sigma_2)\).

As mostras considéranse independentes e supoñemos que as varianzas son descoñecidas e distintas.

Como exemplo, supoñamos de novo unha plataforma de comercio electrónico que compara o tempo medio de resposta do seu sistema en dous servidores distintos. Supoñemos agora que as varianzas dos tempos de resposta en cada servidor son descoñecidas e distintas. Obsérvanse os tempos de 10 usuarios distintos en cada servidor:

  • Servidor 1: \(5.60, 5.10, 5.35, 5.75, 5.20, 5.70, 5.45, 5.30, 5.65, 5.25\)
  • Servidor 2: \(5.10, 4.80, 4.85, 5.20, 4.90, 5.00, 4.95, 4.88, 5.05, 4.92\)

Queremos contrastar se existen diferenzas entre os tempos medios de resposta dos dous servidores.

\[ H_0:\mu_1=\mu_2 \qquad \text{fronte a} \qquad H_1:\mu_1\neq\mu_2 \] En R, realizamos este contraste de novo coa función t.test() indicando agora o argumento var.equal = FALSE.

x1 <- c(5.6, 5.1, 5.35, 5.75, 5.2, 5.7, 5.45, 5.3, 5.65, 5.25)
x2 <- c(5.1, 4.8, 4.85, 5.2, 4.9, 5, 4.95, 4.88, 5.05, 4.92)

t.test(x1, x2, var.equal = FALSE, alternative = "two.sided")
## 
##  Welch Two Sample t-test
## 
## data:  x1 and x2
## t = 5.7263, df = 13.805, p-value = 5.53e-05
## alternative hypothesis: true difference in means is not equal to 0
## 95 percent confidence interval:
##  0.2937289 0.6462711
## sample estimates:
## mean of x mean of y 
##     5.435     4.965

Observamos que o p-valor é moi pequeno (inferior a 0.05), polo que rexeitamos a hipótese nula. Polo tanto, existe evidencia estatística suficiente para concluír que os tempos medios de resposta dos dous servidores son diferentes.

5.3.3 Mostras emparelladas

Consideremos agora unha poboación na que medimos dúas características relacionadas \(X_1\) e \(X_2\) sobre os mesmos individuos. Supoñemos que \(X_1 \sim N(\mu_1, \sigma_1)\) e \(X_2 \sim N(\mu_2, \sigma_2)\), pero tendo en conta que agora \(X_1\) e \(X_2\) non son independentes. Queremos realizar contrastes sobre a diferencia de medias \(\mu_1-\mu_2\). Na práctica, dispoñemos de dúas mostras emparelladas de tamaño \(n\) observadas nos mesmos individuos:

  • \(X_{11}, \dots, X_{1n}\) coa mesma distribución \(N(\mu_1, \sigma_1)\).
  • \(X_{21}, \dots, X_{2n}\) coa mesma distribución \(N(\mu_2, \sigma_2)\).

Como exemplo, un equipo de IA quere avaliar o impacto dunha nova técnica de preprocesamento sobre o tempo de adestramento dun modelo de clasificación de imaxes. Para iso, obtéñense os tempos de adestramento do modelo (en segundos) para 10 imaxes antes e despois de aplicar a técnica.

  • Antes do preprocesamento: \(82, 85, 78, 90, 88, 84, 87, 80, 86, 83\)
  • Despois do preprocesamento: \(85, 88, 80, 92, 90, 86, 89, 82, 88, 85\)

Queremos contrastar se existen diferenzas nos tempos medios de adestramento antes (\(\mu_1\)) e despois (\(\mu_2\)) da técnica de preprocesamento.

\[ H_0:\mu_1=\mu_2 \qquad \text{fronte a} \qquad H_1:\mu_1\neq\mu_2 \] En R, realizamos este contraste coa función t.test() indicando agora o argumento paired = TRUE.

antes <- c(82, 85, 78, 90, 88, 84, 87, 80, 86, 83)
despois <- c(85, 88, 80, 92, 90, 86, 89, 82, 88, 85)

t.test(antes, despois, paired = TRUE, alternative = "two.sided")
## 
##  Paired t-test
## 
## data:  antes and despois
## t = -16.5, df = 9, p-value = 4.917e-08
## alternative hypothesis: true mean difference is not equal to 0
## 95 percent confidence interval:
##  -2.501621 -1.898379
## sample estimates:
## mean difference 
##            -2.2

Á vista do p-valor, rexeitamos a hipótese nula. Polo tanto, existe evidencia estatística suficiente para concluír que os tempos medios de adestramento antes e despois da técnica de preprocesamento son diferentes. Se agora queremos comprobar se o tempo de adestramento é maior despois da técnica de preprocesamento, formulamos un contraste unilateral axeitado e repetimos o procedemento coa opción correspondente en t.test().

\[ H_0:\mu_1\geq\mu_2 \qquad \text{fronte a} \qquad H_1:\mu_1<\mu_2 \]

antes <- c(82, 85, 78, 90, 88, 84, 87, 80, 86, 83)
despois <- c(85, 88, 80, 92, 90, 86, 89, 82, 88, 85)

t.test(antes, despois, paired = TRUE, alternative = "less")
## 
##  Paired t-test
## 
## data:  antes and despois
## t = -16.5, df = 9, p-value = 2.459e-08
## alternative hypothesis: true mean difference is less than 0
## 95 percent confidence interval:
##       -Inf -1.955585
## sample estimates:
## mean difference 
##            -2.2

Observa que escribimos alternative = "less" porque estamos a probar se antes < despois (a hipótese alternativa é \(H_1:\mu_1<\mu_2\)). A partir do resultado obtido, rexeitamos a hipótese nula. Polo tanto, existe evidencia estatística suficiente para concluír que o tempo medio de adestramento é significativamente maior despois da técnica de preprocesamento.

5.4 Contrastes para a razón de varianzas de poboacións normais

Antes de estudar os contrastes para varianzas, é importante destacar que, do mesmo xeito que ocorría nos intervalos de confianza, en R non existe unha función básica específica para realizar contrastes dunha soa varianza. Este tipo de contraste pode abordarse mediante a distribución chi-cadrado, de forma manual ou empregando librerías adicionais. Porén, neste curso non imos tratar este procedemento de forma explícita. Porén, si dispoñemos dunha función directa para comparar dúas varianzas.

Supoñamos dúas poboacións nas que se estudan dúas características distribuídas normalmente con varianzas descoñecidas \(\sigma_1^2\) e \(\sigma_2^2\), respectivamente. O obxectivo é comparar as dúas varianzas a partir de dúas mostras:

  • Unha mostra formada por \(n_1\) variables independentes e coa mesma distribución \(N(\mu_1, \sigma_1)\).
  • Unha mostra formada por \(n_2\) variables independentes e coa mesma distribución \(N(\mu_2, \sigma_2)\).

Os contrastes que se consideran poden ser bilaterais ou unilaterais, dependendo do interese do estudo. É dicir, analizaremos contrastes do tipo

\[ H_0:\sigma_1^2=\sigma_2^2 \qquad \text{fronte a} \qquad H_1:\sigma_1^2\neq\sigma_2^2, \]

ou ben os correspondentes contrastes unilaterais cando se quere determinar se unha das varianzas é maior ou menor ca outra.

Como exemplo, unha plataforma de comercio electrónico quere analizar a variabilidade do tempo de resposta do seu sistema de recomendación en dous servidores distintos. Obsérvanse os tempos de 10 usuarios distintos en cada servidor:

  • Servidor 1: \(5.60, 5.10, 5.35, 5.75, 5.20, 5.70, 5.45, 5.30, 5.65, 5.25\)
  • Servidor 2: \(5.10, 4.80, 4.85, 5.20, 4.90, 5.00, 4.95, 4.88, 5.05, 4.92\)

Supoñendo que os tempos son normais, queremos contrastar se existen diferenzas entre as varianzas dos tempos de resposta dos dous servidores.

x1 <- c(5.6, 5.1, 5.35, 5.75, 5.2, 5.7, 5.45, 5.3, 5.65, 5.25)
x2 <- c(5.1, 4.8, 4.85, 5.2, 4.9, 5, 4.95, 4.88, 5.05, 4.92)

var.test(x1, x2, conf.level = 0.95)
## 
##  F test to compare two variances
## 
## data:  x1 and x2
## F = 3.4564, num df = 9, denom df = 9, p-value = 0.07882
## alternative hypothesis: true ratio of variances is not equal to 1
## 95 percent confidence interval:
##   0.8585332 13.9156468
## sample estimates:
## ratio of variances 
##            3.45645

O resultado do contraste proporciona p-valor de 0.07882. Comparando o p-valor co nivel de significación \(\alpha\), observamos que:

  • Se \(\alpha < 0.07882\), non se rexeita a hipótese nula.
  • Se \(\alpha \ge 0.07882\), rexeitaríase a hipótese nula.

En particular, para valores habituais como \(\alpha = 0.05\), non se rexeita a hipótese nula. Polo tanto, non hai evidencia estatística suficiente para concluír que existan diferenzas significativas entre as varianzas das dúas poboacións (para un nivel de significación \(\alpha = 0.05\) os datos son compatibles coa hipótese de igualdade de varianzas).

Se se quixeran formular contrastes unilaterais, estes poderían realizarse tamén mediante o argumento alternative da función var.test(), indicando se se desexa comprobar se a varianza dunha poboación é maior ou menor ca da outra.

5.5 Contrastes para unha proporción

Ademais dos intervalos de confianza que vimos no tema anterior, tamén podemos realizar contrastes de hipóteses sobre unha proporción.

Consideramos o contraste:

\[ H_0: p = p_0 \qquad \text{fronte a} \qquad H_1: p \neq p_0 \] Na teoría, os contrastes sobre proporcións realízanse empregando a aproximación normal do estimador. En R, a función prop.test() implementa este contraste de forma automática. O argumento correct = FALSE emprégase para desactivar a corrección por continuidade que se aplica ao aproximar a distribución binomial pola normal, facendo que o procedemento sexa máis fiel á formulación teórica vista na aula.

Como exemplo, consideremos un modelo de clasificación de imaxes. Avaliáronse 50 imaxes, das cales 42 foron clasificadas correctamente. Queremos contrastar se a proporción de acerto é significativamente distinta do 90%:

n <- 50
x <- 42

prop.test(x, n, p = 0.9, alternative = "two.sided", correct = FALSE)
## 
##  1-sample proportions test without continuity correction
## 
## data:  x out of n, null probability 0.9
## X-squared = 2, df = 1, p-value = 0.1573
## alternative hypothesis: true p is not equal to 0.9
## 95 percent confidence interval:
##  0.7148578 0.9166258
## sample estimates:
##    p 
## 0.84

Á vista do resultado de prop.test(), para un nivel de significación \(\alpha=0.05\), non existe evidencia estatística suficiente para rexeitar a hipótese nula sobre a proporción.

Observa que intervalo de confianza para a proporción que devolve prop.test() non coincide exactamente co intervalo aproximado calculado na sesión de laboratorio anterior. Isto débese a que non se constrúe de forma idéntica á aproximación normal explicada na teoría.

Igual que nos outros casos, poderíase empregar o argumento alternative da función prop.test(), se o que se desexa é contrastar se a proporción de acerto é significativamente maior ou menor que un valor dado.

5.6 Contrastes para a diferenza de proporcións

Nalgúns casos estamos interesados en contrastar hipóteses sobre a diferenza de proporcións \(p_1 - p_2\) de dúas poboacións. Para iso dispoñemos de dúas mostras independentes:

  • Unha mostra de tamaño \(n_1\) procedente da poboación 1.
  • Unha mostra de tamaño \(n_2\) procedente da poboación 2.

As mostras considéranse independentes, é dicir, os individuos de cada poboación son distintos.

Consideramos o contraste:

\[ H_0: p_1 = p_2 \qquad \text{fronte a} \qquad H_1: p_1 \neq p_2 \]

Como exemplo, comparamos dous modelos de clasificación de imaxes:

  • Modelo A: 42 acertos en 50 imaxes
  • Modelo B: 45 acertos en 50 imaxes

Queremos contrastar se a proporción de acerto é significativamente diferente nos dous modelos. En R realizamos o contraste mediante:

n1 <- 50
x1 <- 42  # Modelo A
n2 <- 50
x2 <- 45  # Modelo B

prop.test(c(x1, x2), c(n1, n2), alternative = "two.sided", correct = FALSE)
## 
##  2-sample test for equality of proportions without continuity correction
## 
## data:  c(x1, x2) out of c(n1, n2)
## X-squared = 0.79576, df = 1, p-value = 0.3724
## alternative hypothesis: two.sided
## 95 percent confidence interval:
##  -0.19130296  0.07130296
## sample estimates:
## prop 1 prop 2 
##   0.84   0.90

Á vista do resultado de prop.test(), para un nivel de significación \(\alpha=0.05\), non existe evidencia estatística suficiente para rexeitar a hipótese nula. Polo tanto, non hai evidencia estatística suficiente para concluír que existan diferenzas significativas entres as proporcións de clasificación correcta dos dous modelos.

De novo, como en todos os casos anteriores poderíase empregar o argumento alternative da función prop.test(), se o que se desexa é contrastar se a proporción de acerto é significativamente maior ou menor no modelo A que no modelo B.
