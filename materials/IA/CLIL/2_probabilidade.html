2  Fundamentos de probabilidade

Vimos que un experimento aleatorio a aquel que cumpre os seguintes requisitos:

  • Todos os seus posibles resultados son coñecidos de antemán.
  • O resultado particular de cada realización do experimento é imprevisible.
  • O experimento pódese repetir indefinidamente en condicións idénticas.

Por exemplo, un experimento aleatorio básico sería lanzar un dado. En R, podemos simular experimentos aleatorios de forma moi sinxela usando as funcións de xeración de números aleatorios.

2.1 A función sample()

Unha das funcións máis empregadas para simular realizacións de experimentos aleatorios é a función sample(), que permite xerar mostras aleatorias (con ou se remplazamento) e permutacións a partir de conxunto de valores.

Unha permutación é unha ordenación aleatoria dos elementos dun vector. En sample() isto é o que se devolve por defecto, cando non se especifica ningún outro argumento da función.

sample(1:6) # permutación dos números 1 a 6

Nós imos empregar a función sample() para simular un lanzamento de dado. O que teríamos que facer é:

sample(1:6, size = 1)

O segundo argumento, size, é o número de elementos a xerar. Por defecto, a mostra xérase sen reposición. Se queremos que o proceso se realice con reposición, necesitaremos empregar o terceiro argumento replace = TRUE.

sample(1:6, size = 4) # 4 números entre {1,2,...,6} (sen reposición)
sample(1:6, size = 4, replace = TRUE) # 4 números entre {1,2,...,6} (con reposición)

Observa que sempre que executas a primeira orde, os catro número elixidos son diferentes. Coa segunda opción, poden aparecer valores repetidos.

Fíxate no seguinte exemplo, no que simulamos 10, 100, 1000 e 10000 lanzamentos dun dado e calculamos a frecuencia de aparición de cada resultado.

x <- sample(1:6, size = 10, replace = TRUE)
table(x) / length(x)

x <- sample(1:6, size = 100, replace = TRUE)
table(x) / length(x)

x <- sample(1:6, size = 1000, replace = TRUE)
table(x) / length(x)

x <- sample(1:6, size = 10000, replace = TRUE)
table(x) / length(x)

Aínda que non estamos a lanzar dados reais, os resultados son equivalentes e permiten explorar conceptos como o de probabilidade a través da súa definición frecuentista, observando como se comportan as frecuencias relativas cando aumentamos o número de lanzamentos.

A función sample() tamén permite xenerar números aleatorios dun conxunto onde non todos os valores son equiprobables usando o argumento prob. Por exemplo, supoñamos que queremos simular 10 lanzamentos dunha moeda na que a probabilidade de cara é 0.7. Poderiamos facer:

sample(c("cara", "cruz"), size = 10, replace = TRUE, prob = c(0.7, 0.3))
TipO problema do cabaleiro de Meré

No século XVII, os xogos de azar eran a principal diversión da alta sociedade francesa. Antoine Gombard, Cabaleiro de Meré, preguntoulle a Blaise Pascal (1623–1662) durante unha viaxe se era vantaxoso apostar polo resultado de obter polo menos un seis nunha serie de catro lanzamentos dun dado. Pascal e Pierre de Fermat (1601–1665) mantiveron abundante correspondencia sobre este e outros problemas relacionados co cálculo de probabilidades. No seguinte tema veremos como resolver o problema de forma exacta empregando a distribución binomial.

Se non fósemos capaces de obter a solución exacta, poderiamos abordar o problema mediante simulación. A idea sería repetir moitas veces a situación descrita, é dicir, simular un gran número de series de catro tiradas dun dado. A continuación, calculariamos a proporción de veces nas que aparece polo menos un seis. Esa frecuencia relativa proporcionaría unha aproximación da probabilidade buscada, que se iría achegando á solución analítica exacta canto maior fose o número de simulacións realizadas.

Para facer isto en R, precisaremos empregar estruturas de control como bucles, que nos permiten repetir un mesmo experimento moitas veces, e tamén sentenzas condicionais, que serven para comprobar se nunha simulación se cumpre ou non o evento de interese (por exemplo, se apareceu algún seis nas catro tiradas).

En R, un bucle for permite repetir un mesmo bloque de instrucións un número determinado de veces. A súa sintaxe é:

for (i in obxecto) {
  comandos
}

Isto significa que a variable i toma sucesivamente os valores de obxecto, e en cada iteración execútanse os comandos que están dentro das chaves. Existen tamén bucles while

while (condición) {
  comandos
}

que executan as instrucións dadas en comandos mentres a condición establecida entre parénteses sexa verdadeira (TRUE). Pola súa parte, unha sentenza condicional if permite executar un código só cando se cumpre unha condición:

if (condición) {
  comandosA
} else {
  comandosB
}

Se condición é verdadeira (TRUE), execútanse os comandosA. Se é falsa (FALSE), execútanse os comandosB.

No seguinte código simulamos B = 1000 series de catro tiradas dun dado. En cada simulación contamos cantos seises aparecen. Se aparece polo menos un, a condición do if cúmprese e sumamos 1 ao contador de victorias win. Finalmente, calculamos a frecuencia relativa de éxito como aproximación da probabilidade buscada.

win <- 0 # Número de veces que gaña Mere
B <- 1000 # Número de apostas
for (i in 1:B) {
  dice <- sample(1:6, 4, replace = TRUE) # catro lanzamentos dun dado
  n6 <- sum(dice == 6) # Número de 6's nos catro lanzamentos dun dado
  if (n6 >= 1) {
    win <- win + 1
  }
}
fwin <- win / B # Frecuencia de polo menos un seis (probabilidade aproximada)
fwin

2.2 Reproducibilidade

En moitas ocasións necesitamos que os resultados sexan reproducibles: que outra persoa (ou ti mesmo noutro momento) poida obter exactamente os mesmos resultados ao executar o mesmo código.

En R, moitas funcións aleatorias (como sample()) xeran números baseándose nun xerador de números pseudoaleatorios. Isto significa que os números non son verdadeiramente aleatorios, senón que se obtén unha secuencia determinista a partir dun estado inicial (semente). A función set.seed() establece ese estado inicial. Ao fixar a semente, garantimos que a secuencia de números aleatorios será sempre a mesma. O recomendable é establecer un número enteiro, como no seguinte exemplo.

set.seed(123)
sample(1:6)
sample(1:6)

set.seed(123)
sample(1:6)
sample(1:6)
